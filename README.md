# Fortune Cookie for the Liquidated Trader

A single fortune-cookie line for a crypto trader who has just been
liquidated, written by a small Python program.

Running `main.py` writes one line of plain text to `/output/entry.txt`:

> Your portfolio has achieved enlightenment: it is now one with the void.

The fortune keeps the classic cookie voice (small, oracular, slightly
formal) and lets the punchline break it: the portfolio has not vanished,
it has simply reached a higher state of being. Rueful, warm, and short
enough to read in one breath at 3am with an empty wallet.

## Run

```sh
python3 main.py
```
